# Tamil Nadu Calendar 2026 📅

A responsive and interactive **Tamil Nadu Calendar 2026** website featuring Tamil Nadu government holidays, festivals, and important dates.

## 🌐 Live Website

[View Tamil Nadu Calendar 2026](https://tamil-nadu-calendar-2026.vercel.app/)

## ✨ Features

- 📅 Complete 2026 calendar
- 🇮🇳 Tamil Nadu government holidays
- 🎉 Festivals and important dates
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Modern glassmorphism UI
- ✨ Smooth scroll animations
- 🔄 Dynamic calendar data loaded from JSON
- ⚡ Fast and lightweight static website

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Git & GitHub
- Vercel
